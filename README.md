# Auto Mace (Fabric 1.21.11, singleplayer only)

Build:   ./gradlew build        (Windows: gradlew.bat build)   -> jar in build/libs/automace-1.0.0.jar
Test:    ./gradlew runClient
Needs:   JDK 21 or newer, Fabric Loader 0.19.5+, Fabric API 0.141.6+1.21.11 (or newer for 1.21.11)

Use: put a mace (and optionally an axe) in your HOTBAR. Right Shift opens the settings.
